The driver contract now documents that the Supabase driver, like S3, Azure and Cloudinary, resolves a `delete` of a missing object quietly. The Azure driver pins every TUS chunk append to its offset so a resent chunk fails with 412 instead of duplicating bytes, skips `folder/` placeholder blobs in `list()`, and refuses a properties response missing size or modification time instead of returning `undefined`. The Cloudinary driver quotes and pins the `list()` search expression to the `public_id` field so a caller-controlled prefix cannot become a boolean query listing the whole account, signs requests with a timestamp in seconds per the signing spec, percent-encodes delivery URLs so public ids containing `?` or `#` still address one asset, rejects an empty `write` instead of resolving while nothing is stored and a previous asset survives, checks the TUS chunk size on the running total while the chunk is still streaming, converts string chunks to buffers the way `write` does, derives the upload chunk size from `MINIMUM_CHUNK_SIZE`, and reads a 2xx non-JSON search answer as an empty page. The GCS driver validates `tus.chunkSize` whenever it is configured — not only when resumable uploads are enabled — and refuses a metadata record missing size or modification time instead of returning `NaN`/`Invalid Date`. The local driver reports a directory from `exists()`/`stat()` as absent like the object stores do, removes the temporary file when the publishing `rename` of `write()` fails, and skips in-flight `.<random>.tmp` staging files in `list()`. The S3 driver accepts chunks of deferred-length uploads by sizing parts for the largest object and recognising no part as final until the length is declared, refuses a HEAD response missing size or modification time, and parses a custom `endpoint` with the URL parser so a path prefix and a port reach the SDK intact. The Supabase driver percent-encodes object names in the authenticated download URL so names containing `?` or `#` address the right object, splits lookup names on `/` alone instead of the platform separator, and resumes a deferred-length upload with a `null` size, the previous-upload contract's marker for an unknown total.
