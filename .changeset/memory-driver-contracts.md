The driver contracts of `@novastarter/memory` are now `KvDriver`, `CacheDriver`, `BusDriver` and `LimiterDriver` — the `Driver` suffix every other subsystem uses — so rename the `Kv`, `Cache`, `Bus` and `Limiter` types in calling code; `KvDriverLocal` and `CacheDriverLocal` can now be constructed without a config object. `CacheDriverMulti` gains `close()`, which quits the subscriber connection its bus opened, and surfaces a failed subscription on the first write instead of as an unhandled rejection; `KvDriverRedis.increment` and `setMax` give the key the configured `ttl` like `set` does, where a key they created used to live for good, and an `INCRBY` that fails inside that transaction throws instead of answering `0`; a lock from `KvDriverRedis.acquireLock` can be extended more than once, where the second `extend()` used to throw "already expired" because the handle kept the lock object Redlock had invalidated; `KvDriverRedis.setMax` answers `false` for a value that was not stored (the Lua script answered `false`, which Redis turns into `nil`, so it used to read as `true`), `clear()` skips the empty batches `SCAN` may answer with, and the unused `release` command is no longer defined on the client. `KvDriverLocal` locks for real — one holder per key at a time within the process, where `acquireLock` used to hand out a no-op — and a bus handler may be async: a subscriber that throws or rejects is logged through `@novastarter/logger` (now a dependency) instead of being swallowed by the local bus or left as an unhandled rejection by the Redis one — once per subscriber and channel until it succeeds there again, so a broken one neither floods the log nor, when the log itself travels over the bus, feeds itself. The Redis bus logs a message it cannot decode instead of dying on an unhandled rejection, and a failed `SUBSCRIBE` leaves no half-registered channel behind — every `subscribe()` that joined while it was under way learns of the failure too — so a retry subscribes for real; `CacheDriverMulti` subscribes again on the next write after a failed subscription instead of staying dead for the rest of the process. `KvDriverLocal.setMax` stores any number on a missing key, as the Redis script does, where it used to refuse a zero or negative one.
