The driver contracts of `@novastarter/memory` are now `KvDriver`, `CacheDriver`, `BusDriver` and `LimiterDriver` — the `Driver` suffix every other subsystem uses — so rename the `Kv`, `Cache`, `Bus` and `Limiter` types in calling code; `KvDriverLocal` and `CacheDriverLocal` can now be constructed without a config object. `CacheDriverMulti` gains `close()`, which quits the subscriber connection its bus opened, and surfaces a failed subscription on the first write instead of as an unhandled rejection; `KvDriverRedis.increment` and `setMax` give the key the configured `ttl` like `set` does, where a key they created used to live for good, and an `INCRBY` that fails inside that transaction throws instead of answering `0`; `KvDriverRedis.setMax` answers `false` for a value that was not stored (the Lua script answered `false`, which Redis turns into `nil`, so it used to read as `true`), `clear()` skips the empty batches `SCAN` may answer with, and the unused `release` command is no longer defined on the client. `KvDriverLocal` locks for real — one holder per key at a time within the process, where `acquireLock` used to hand out a no-op — and a bus handler may be async: a subscriber that throws or rejects is logged through `@novastarter/logger` (now a dependency) instead of being swallowed by the local bus or left as an unhandled rejection by the Redis one.
