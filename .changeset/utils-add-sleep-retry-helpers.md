'@novastarter/utils': minor

Add `sleep`, `retry`, `toNumber`, `tryParseJSON` and `joinPath` to the shared entry point: a promise pause with abort support, a retry loop with configurable pacing, jitter, `shouldRetry` and `onRetry` that refuses a `retries` budget that is not a whole number and a `jitter` outside `0`–`1` (`NaN` included), and throws a `RangeError` naming `delay`, `factor` and `maxDelay` — with the attempt's error as `cause` — when they give a negative or `NaN` pause and caps every pause at 30 s by default and at what a timer can hold (`MAX_TIMER_DELAY`, which `sleep` refuses to exceed), a strict number cast that answers `undefined` instead of `NaN`, a `parseJSON` that falls back instead of throwing, a platform-neutral `path.posix.join` for object keys and URL paths that answers `/` for segments made only of separators, and `confinePath`, which resolves a caller path as if rooted and makes it relative, so `..` cannot climb above the root it is joined to; both refuse a segment that is not a string with a `TypeError` instead of dropping it, and `normalizePath` answers `/` for a run of separators, `''` with `removeLeading`. `retry` ends with the abort reason, without calling `onRetry`, when the signal aborted during a failing attempt.
